# 解答

**问题设定**：设 $P = \text{TENETENET}$（长度 9）。字母独立、均匀（每个概率 $1/26$）。设 $T$ 为 $P$ 第一次作为连续子串出现时已输出的字母总数，求 $E[T]$。

## 一、模式的自重叠结构（border）

模式失配时能“保住”多少进度，取决于 $P$ 的 **border**（既是 $P$ 前缀又是 $P$ 后缀的串）。逐一比对：

| $k$ | 前 $k$ 位 | 后 $k$ 位 | 相等？ |
|---|---|---|---|
| 1 | T | T | ✓ |
| 2 | TE | ET | ✗ |
| 3 | TEN | NET | ✗ |
| 4 | TENE | ENET | ✗ |
| 5 | TENET | TENET | ✓ |
| 6 | TENETE | ETENET | ✗ |
| 7 | TENETEN | NETENET | ✗ |
| 8 | TENETENE | ENETENET | ✗ |

即 $P$ 恰有两个真 border：长度 1（"T"）和长度 5（"TENET"）。

## 二、匹配状态机

以“当前串的最长后缀 = $P$ 的前缀”的长度 $i$（$0\le i\le 8$）为状态，$i=9$ 表示完成。由于 $P$ 的所有前缀都以 **T** 开头，判定新状态只需检查新串中**以 T 开头的后缀**。逐状态验证：

| 状态 | 字母 $c$ | 新串 | 以 T 开头的后缀中的最长 $P$ 前缀 | 新状态 |
|---|---|---|---|---|
| 0 | T / 其他 | T / … | T / 无 | 1 / 0 |
| 1 (T) | E / T / 其他 | TE / TT / Tc | TE / T / 无 | 2 / 1 / 0 |
| 2 (TE) | N / T / 其他 | TEN / TET / TEc | TEN / T / 无 | 3 / 1 / 0 |
| 3 (TEN) | E / T / 其他 | TENE / TENT / TENc | TENE / T / 无 | 4 / 1 / 0 |
| 4 (TENE) | T / 其他 | TENET / TENEc | **TENET** / 无 | **5** / 0 |
| 5 (TENET) | E / T / 其他 | TENETE / TENETT / TENETc | TENETE / T / 无 | 6 / 1 / 0 |
| 6 (TENETE) | N / T / 其他 | TENETEN / TENETET / TENETEc | TENETEN / T / 无 | 7 / 1 / 0 |
| 7 (TENETEN) | E / T / 其他 | TENETENE / TENETENT / TENETENc | TENETENE / T / 无 | 8 / 1 / 0 |
| 8 (TENETENE) | T / 其他 | TENETENET / TENETENEc | **完成** / 无 | 完成 / 0 |

（验证示例：TENETT 的 T 开头后缀为 T、TT、TENETT，仅 "T" 是 $P$ 前缀；TENETET 的为 T、TET、TENETET，仅 "T"；TENETENT 的为 T、TENT、TENETENT，仅 "T"；TENETN 的为 TENETN、TN，均非前缀；TENETENEN 的为 TENETENEN、TENEN，均非前缀，等等。）

## 三、期望方程

设 $x_i$ = 从状态 $i$ 出发到完成还需的期望字母数（$x_9=0$），所求为 $x_0$。由一步分析：

$$x_0 = 1 + \tfrac{1}{26}x_1 + \tfrac{25}{26}x_0 \tag{0}$$
$$x_i = 1 + \tfrac{1}{26}x_{i+1} + \tfrac{1}{26}x_1 + \tfrac{24}{26}x_0,\quad i=1,2,3,5,6,7$$
$$x_4 = 1 + \tfrac{1}{26}x_5 + \tfrac{25}{26}x_0,\qquad x_8 = 1 + \tfrac{25}{26}x_0$$

（该方程组来自吸收马尔可夫链，吸收几乎必然且期望有限，解唯一。）

## 四、求解

由 (0)：$x_1 = x_0 - 26$。代入 $i=2,3,5,6,7$ 的方程，常数 $1$ 与 $\tfrac1{26}\cdot(-26)=-1$ 相消，得
$$x_i = \tfrac1{26}x_{i+1} + \tfrac{25}{26}x_0 \quad\Rightarrow\quad z_i := x_i - x_0 = \tfrac{1}{26}z_{i+1}.$$

而 $z_8 = 1 - \tfrac{x_0}{26}$，$z_4 = 1 + \tfrac{z_5}{26}$。逐级递推：

$$z_7=\tfrac1{26}-\tfrac{x_0}{26^2},\ z_6=\tfrac1{26^2}-\tfrac{x_0}{26^3},\ z_5=\tfrac1{26^3}-\tfrac{x_0}{26^4},\ z_4=1+\tfrac1{26^4}-\tfrac{x_0}{26^5},\ z_3=\tfrac1{26}+\tfrac1{26^5}-\tfrac{x_0}{26^6},\ z_2=\tfrac1{26^2}+\tfrac1{26^6}-\tfrac{x_0}{26^7}.$$

最后用 (1)（乘 26 化为 $25x_1 = 26 + x_2 + 24x_0$），代入 $x_1 = x_0-26$、$x_2 = x_0+z_2$：

$$25(x_0-26)=26+(x_0+z_2)+24x_0 \;\Rightarrow\; z_2 = -676 = -26^2.$$

于是
$$\tfrac1{26^2}+\tfrac1{26^6}-\tfrac{x_0}{26^7} = -26^2 \;\Rightarrow\; x_0 = 26^9 + 26^5 + 26.$$

## 五、数值计算

$$26^5 = 11{,}881{,}376,\qquad 26^9 = 26^5\cdot 26^4 = 11{,}881{,}376 \times 456{,}976 = 5{,}429{,}503{,}678{,}976$$
$$E[T] = 26^9 + 26^5 + 26 = 5{,}429{,}503{,}678{,}976 + 11{,}881{,}376 + 26 = 5{,}429{,}515{,}560{,}378.$$

## 六、交叉验证

经典结论：均匀独立字母下，模式的期望等待时间 $=\sum_{k\in \text{border 长度}\cup\{9\}} 26^k$（可用“赌客公平下注”鞅论证证明：每位赌客带 1 枚筹码，按公平赔率 26 倍连续押注模式的字母；在首次完成时刻 $T$，仍连胜的赌客恰对应各 border 长度 $k$，财富为 $26^k$；公平性给出 $E[T]=\sum 26^k$）。$P$ 的 border 为 $\{1,5,9\}$，故 $E[T] = 26+26^5+26^9$，与状态机求解完全一致。直观地：$26^9$ 是无自重叠的基准值，额外的 $26^5$ 与 $26$ 正对应两个自重叠结构——重叠越多，首次出现越难。

最终答案：5429515560378
