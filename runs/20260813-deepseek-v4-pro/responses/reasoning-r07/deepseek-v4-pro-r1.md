规律是：三字母单词重排后，除原词本身外，**恰好只能得到 1 个不同的常见英文单词**。

题干验证：

- dad → add（1 个）
- dab → bad（1 个）
- gut → tug（1 个）
- low → owl（1 个）
- cat → act（1 个）

反面验证：

- ear → are、era（2 个，不符合）
- cop → 没有其他常见词
- ego → 没有其他常见词
- mom → 没有其他常见词
- ate → eat、tea（2 个，不符合）

选项判断：

- A. leg → gel（1 个，符合）
- B. dam → mad（1 个，符合）
- C. rat → art、tar（2 个，不符合）
- D. car → arc（1 个，符合）
- E. bin → nib（1 个，符合）

所以，不符合该规律的是 **C. rat**。

最终答案：C
