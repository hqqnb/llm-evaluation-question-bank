## 玩法与机制

- 鼠标按住拖动瞄准并蓄力（虚线为飞行轨迹预览，左侧有力度条），松开射箭；按住不动也会持续加力
- 箭矢受重力与每局随机的风向影响，HUD 实时显示风向风力
- 四个环形靶子固定分布，命中后靶面变暗并打勾；箭矢会真实插在靶上
- 开局即计时，命中全部 4 个目标停表；按用时升序排名写入本机排行榜（同时记录箭数与日期），刷新页面后记录仍在，支持一键清空
- 计时、剩余目标、箭数显示在顶部；按 `R` 随时重开

## 运行方式

直接用浏览器打开 `index.html` 即可，或在项目目录起一个本地静态服务器：

```bash
cd "/Users/zay/Documents/模型测评/codex-runs/20260813-deepseek-v4-pro/coding-c06"
python3 -m http.server 8000
# 访问 http://localhost:8000/
```

推荐 Chrome / Edge / Safari 现代版本；排行榜数据存在浏览器 localStorage，换浏览器或清除站点数据会重置。
