把目标字符串记为

P = TENETENET，长度 m = 9，q = 26。

用经典的“公平赌局”方法来求首次出现所需步数的期望。

每轮有一位新赌徒入场，押 1 元赌“下一个字母是 P 的第 1 个字母”。若押中，则赢得 26 元并全部继续押“下下一个字母是 P 的第 2 个字母”，如此继续；一旦押错就输光离场。由于每个字母等概率且独立，每笔赌注都是公平的。设首次完整出现 P 时共用了 N 个字母，那么庄家此前一共收到了 N 元赌注，因此庄家的期望总赔付就等于 E[N]。

当 P 在时刻 N 首次完整出现时，场上仍存活的赌徒必然是：其连续押中的字母串既等于 P 的前缀，又等于 P 的末尾后缀。若某赌徒已连中 k 个字母，则他当前持有 26^k 元。更早入场且存活更久的赌徒会使 P 提前出现，与“首次”矛盾，所以赔付总额恰好是所有这类重叠长度 k 对应的 26^k 之和：

E[N] = ∑_{k 是 P 的 border} 26^k。

其中 border 指长度 1≤k≤9 且“P 的前 k 个字母 = P 的后 k 个字母”。

P = T E N E T E N E T，逐一检查：

- k=1：T 与 T 相同，成立；
- k=2：TE 与 ET 不同；
- k=3：TEN 与 NET 不同；
- k=4：TENE 与 ENET 不同；
- k=5：TENET 与 TENET 相同，成立；
- k=6：TENETE 与 ETENET 不同；
- k=7：TENETEN 与 NETENET 不同；
- k=8：TENETENE 与 ENETENET 不同；
- k=9：整个字符串自身，总是成立。

因此 border 长度为 k = 1, 5, 9，于是

E[N] = 26^1 + 26^5 + 26^9
     = 26 + 11,881,376 + 5,429,503,678,976
     = 5,429,515,560,378。
