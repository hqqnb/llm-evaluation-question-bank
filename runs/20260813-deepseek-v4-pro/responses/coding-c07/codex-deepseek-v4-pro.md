## 实现内容

- 3D 地球：4096×2048 NASA 蓝大理石日间纹理 + 夜间灯光纹理，自研 GLSL 着色器按太阳方向混合出柔和日夜分界线；菲涅尔大气光晕、星空背景、自转动画。
- 数据层：63 个国家热力着色（topojson 110m 边界按指标实时重绘 canvas），33 个发光城市标记（呼吸脉冲 + 城市名称），23 条二次贝塞尔航线弧带流动光波。
- 交互：OrbitControls 拖拽旋转/滚轮缩放；点击城市弹出信息卡（指标值、2010–2025 趋势迷你图、人口/航班/GDP）；悬停航线显示航班信息并高亮。
- 控制面板：GDP / 人口 / 航班量三指标切换、时间轴滑块 + 播放（含 2020–2021 疫情回落模拟）、自转/光晕/热力/夜灯/航线/标签开关、动态图例。
- 技术：importmap + ESM，Three.js 0.170 + OrbitControls + topojson-client，全部从 CDN 加载；纹理加载失败时自动降级为程序化生成的陆地/城市灯光纹理，国家边界获取失败时热力层自动禁用，保证离线也能运行。
