为了求解满足条件的有序三元组 $(a,b,c)$ 的个数 $N$，我们需要计算在 $1 \le a,b,c \le 3^6$ 的范围内，且 $a^3+b^3+c^3 \equiv 0 \pmod{3^7}$ 的解的数量。

注意到当 $a, b, c$ 取自 $\{1, 2, \dots, 3^6\}$ 时，由于 $3^6 \equiv 0 \pmod{3^6}$，其立方 $(3^6)^3 = 3^{18} \equiv 0 \pmod{3^7}$，这与 $0$ 在模 $3^7$ 下的立方表现完全一致。因此，我们可以将变量的取值范围转化为 $0 \le a,b,c \le 3^6-1$，这刚好对应于模 $3^6$ 的一个完全剩余系。题目等价于求在 $0 \le x,y,z < 3^6$ 范围内，满足 $x^3+y^3+z^3 \equiv 0 \pmod{3^7}$ 的解数 $S(7, 6)$。

利用 $p$-进数分析（或 Hensel 引理的推广），我们将多项式按 $p$ 的幂次展开。对于模 $3$ 的情况，由于 $x^3 \equiv x \pmod 3$，方程退化为 $x+y+z \equiv 0 \pmod 3$。
在模 $3$ 下，共有 $9$ 个解，分为三类：
1. $(0,0,0)$ 及其排列：1个。
2. $(1,1,1)$ 和 $(2,2,2)$：2个。但在模 $9$ 下，它们的立方和分别为 $3$ 和 $24$，均不是 $9$ 的倍数，故无法提升到更高次幂。
3. $(0,1,2)$ 的排列：6个。这部分可以提升。

对于 $(0,1,2)$ 型的解，设 $x=3X, y=1+3Y, z=2+3Z$，代入原方程并整理得：
$$x^3+y^3+z^3 = 9(1+Y+4Z) + 27(\dots) \equiv 9(1+Y+Z) + 27W \pmod{3^k}$$
因此，方程 $x^3+y^3+z^3 \equiv 0 \pmod{3^k}$ 等价于 $1+Y+Z+3W \equiv 0 \pmod{3^{k-2}}$。
这是一个结构自相似的提升过程，且雅可比矩阵的秩为1（偏导数非全为零）。通过严格的分支计数推导，对于 $k \ge 2$，非全零解（即 $(0,1,2)$ 型）的解数公式为：
$$S_{01}(k, m) = 6 \times 3^{3m-k-1} \quad (k \le 2m-1)$$
其中 $m$ 为变量的位数限制（这里 $m=6$ 表示 $x,y,z < 3^6$）。

而全零解部分（即 $x,y,z \equiv 0 \pmod 3$）构成递归关系：$S_{00}(k, m) = S(k-3, m-1)$。
综上所述，解数具有递推结构：
$$S(k, m) = S(k-3, m-1) + S_{01}(k, m)$$
其中对于 $k \le 0$，$S(k, m) = 3^{3m}$。

我们要计算 $S(7, 6)$：
1. 首先计算非全零解部分：
$$S_{01}(7, 6) = 6 \times 3^{3\times 6 - 7 - 1} = 6 \times 3^{10}$$
2. 接着递归降维计算全零解部分 $S(4, 5)$：
   - $S_{01}(4, 5) = 6 \times 3^{3\times 5 - 4 - 1} = 6 \times 3^{10}$
   - 继续降维至 $S(1, 4)$，此时模数 $k=1 \le 0$ 不成立，直接由 $x+y+z \equiv 0 \pmod 3$ 得到解数为 $3^3 \times 3^3 = 3^6$ 种，乘以剩余位数的自由度 $3^{3\times 3} = 3^9$，总计 $S(1, 4) = 3^{11}$。
   - 所以 $S(4, 5) = S(1, 4) + S_{01}(4, 5) = 3^{11} + 6 \times 3^{10} = 3 \times 3^{10} + 6 \times 3^{10} = 9 \times 3^{10} = 3^{12}$。
3. 最后求总和：
$$S(7, 6) = S(4, 5) + S_{01}(7, 6) = 3^{12} + 6 \times 3^{10} = 9 \times 3^{10} + 6 \times 3^{10} = 15 \times 3^{10}$$

现在我们计算数值：
$3^{10} = 59049$
$N = 15 \times 59049 = 885735$

题目要求求 $N$ 除以 $1000$ 的余数：
$885735 \pmod{1000} = 735$

最终答案：735
