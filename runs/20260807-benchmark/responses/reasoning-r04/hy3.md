设 $X$ 为一次实验中出现正面的硬币数量。用指示变量 $I_1,I_2,I_3$ 表示三枚硬币的结果，其中 $I_i=1$ 表示第 $i$ 枚硬币为正面，$I_i=0$ 表示反面，则 $X = I_1+I_2+I_3$。

已知每枚硬币出现正面的边际概率为 $1/3$，即对任意 $i$ 都有 $P(I_i=1)=1/3$，因此 $E[I_i]=1/3$。

题目指出“在每次实验中，出现反面的硬币数量一定是偶数”。由于一共只有 3 枚硬币，反面数量只能是 0 或 2（不可能出现其他偶数），所以正面数量 $X = 3 - \text{反面数量}$ 只能取 3 或 1。换句话说，随机变量 $X$ 几乎必然取值于集合 $\{1, 3\}$。

根据期望的线性性质（无论变量是否独立都成立），正面总数的期望为：
$$E[X] = E[I_1+I_2+I_3] = E[I_1] + E[I_2] + E[I_3] = \frac13 + \frac13 + \frac13 = 1.$$

另一方面，设 $p = P(X=3)$，即三枚硬币同时出现正面的概率。由于 $X$ 只能取 1 或 3，故 $P(X=1) = 1-p$。于是期望也可写为：
$$E[X] = 1 \cdot P(X=1) + 3 \cdot P(X=3) = 1 \cdot (1-p) + 3p = 1 + 2p.$$

将两式等同，得到：
$$1 + 2p = 1 \quad \Rightarrow \quad 2p = 0 \quad \Rightarrow \quad p = 0.$$

因此，三枚硬币同时出现正面的概率只能是 0。这也说明在该约束下，实验必然恰好出现一枚正面、两枚反面（例如三种“一正两反”的结果各以概率 $1/3$ 出现），既满足每枚硬币正面的边际概率为 $1/3$，又保证反面数量恒为偶数。

最终答案：0
