# 推理过程

## 分析可能的结果

每次实验中，反面（tails）的数量一定是偶数。三枚硬币的反面数量可能是 0, 1, 2, 3，其中偶数为 **0 或 2**。

因此有效的结果只有两类：

- **0 个反面**：即三枚全是正面 HHH。
- **2 个反面**：即恰好 1 枚正面，共三种：HTT, THT, TTH。

其余情况（1 个反面或 3 个反面）概率为 0。

## 设定变量

设：
- $p_0 = P(\text{HHH})$（我们要求的量）
- $a = P(\text{HTT}),\ b = P(\text{THT}),\ c = P(\text{TTH})$

概率归一化：
$$p_0 + a + b + c = 1 \quad (1)$$

## 利用边际概率

每枚硬币正面概率为 $1/3$。

- 硬币 1 出现正面：只在 HHH 或 HTT 中，故 $p_0 + a = 1/3$
- 硬币 2 出现正面：只在 HHH 或 THT 中，故 $p_0 + b = 1/3$
- 硬币 3 出现正面：只在 HHH 或 TTH 中，故 $p_0 + c = 1/3$

由此：
$$a = b = c = \frac{1}{3} - p_0$$

## 求解

代入归一化条件 (1)：
$$p_0 + 3\left(\frac{1}{3} - p_0\right) = 1$$
$$p_0 + 1 - 3p_0 = 1$$
$$-2p_0 = 0 \implies p_0 = 0$$

## 验证

用期望验证：正面总数的期望为 $3 \times \frac{1}{3} = 1$。

另一方面，期望 $= 3\cdot p_0 + 1\cdot(a+b+c) = 3p_0 + (1-p_0) = 1 + 2p_0$。

令其等于 1，得 $p_0 = 0$。一致。

此时 $a=b=c=1/3$，构成一个合法的概率分布，满足所有约束。

最终答案：0
