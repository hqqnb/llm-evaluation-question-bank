## 设定

三枚硬币，每次实验中出现反面的硬币数只能是偶数，即 0 或 2。因此样本空间只剩下 4 种可能结果：

- 0 个反面：HHH，概率记为 $p$
- 2 个反面：恰好一枚正面，分别为 HTT、THT、TTH，概率记为 $a_1,a_2,a_3$

（1 个反面和 3 个反面对应反面数为奇数，概率必须为 0。）

## 建立方程

归一化条件：
$$p + a_1 + a_2 + a_3 = 1$$

边际概率条件：硬币 $i$ 出现正面只有两种情况——三枚全正（HHH），或只有它一枚正面。所以
$$P(\text{硬币 }i\text{ 正}) = p + a_i = \frac13,\quad i=1,2,3$$

## 求解

把三个边际条件相加：
$$3p + (a_1+a_2+a_3) = 1$$

由归一化条件得 $a_1+a_2+a_3 = 1-p$，代入：
$$3p + (1-p) = 1 \;\Longrightarrow\; 2p = 0 \;\Longrightarrow\; p = 0$$

## 验证

$p=0$ 时 $a_1=a_2=a_3=\frac13$，即分布为 HTT、THT、TTH 各占 $1/3$。检验：
- 每枚硬币正面的边际概率 $=1/3$ ✓
- 每次实验反面数恒为 2，是偶数 ✓
- 概率和为 1 ✓

该解由方程组唯一确定，所以这是唯一满足条件的联合分布，三枚同时为正面是不可能事件。

最终答案：0
