## 推理过程

首先需要准确理解规律。题目说"将单词中的全部字母重新排列后，**恰好**能得到一个不同的常见英文单词"——关键词是"恰好一个"。

**验证"符合"的样例（恰好产生1个不同的常见词）：**
- dad → add（仅此1个）✓
- dab → bad（仅此1个）✓
- gut → tug（仅此1个）✓
- low → owl（仅此1个）✓
- cat → act（仅此1个）✓

**验证"不符合"的样例：**
- ear → are、era（产生2个不同词，不是"恰好一个"）✗
- cop → 无其他常见词 ✗
- ego → 无其他常见词 ✗
- mom → 无其他常见词 ✗
- ate → eat、tea、eta（多个）✗

可见规律包含两层约束：(1) 必须存在不同的常见词；(2) **恰好一个**，不能多也不能少。

**逐项检查选项：**
- A. leg → gel（仅1个）✓ 符合
- B. dam → mad（仅1个）✓ 符合
- C. rat → art、tar（**2个**不同常见词）✗ 不符合
- D. car → arc（仅1个）✓ 符合
- E. bin → nib（仅1个）✓ 符合

`rat` 的字母 r-a-t 可重排成 `art` 和 `tar` 两个不同的常见词，违反"恰好一个"的要求。

最终答案：C
