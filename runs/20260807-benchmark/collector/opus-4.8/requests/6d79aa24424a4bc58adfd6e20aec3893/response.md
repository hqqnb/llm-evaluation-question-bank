# 分析

先把六类糖果列出：

| | 苹果味 | 桃子味 | 西瓜味 |
|---|---|---|---|
| 圆形 | AC=7 | PC=9 | WC=8 |
| 五角星 | AS=7 | PS=6 | WS=4 |

总数 = 7+7+9+6+8+4 = 41。

## 目标条件

需要满足以下之一：
- 圆形苹果 + 五角星桃子：AC≥1 且 PS≥1
- 圆形桃子 + 五角星苹果：PC≥1 且 AS≥1

## 最坏情况（尽量避免满足条件）

要"保证"成功，需考虑对手故意让我们摸得最不利的情况。避免满足条件即要求：

- （AC=0 或 PS=0）且（PC=0 或 AS=0）

西瓜味（8+4=12 个）与目标完全无关，可以全部摸出。

在苹果、桃子里，为使摸出的数量最多（拿走贡献最大的类别），需选择"清零"哪两类，且清零的类别之和尽量小：

- 第一个括号：舍弃 AC(7) 或 PS(6)
- 第二个括号：舍弃 PC(9) 或 AS(7)

各组合保留量：
- 舍 AC、PC → 保留 AS+PS = 13
- 舍 AC、AS → 保留 PC+PS = 15
- 舍 PS、PC → 保留 AC+AS = 14
- 舍 PS、AS → 保留 AC+PC = **16** ← 最大

所以最不利的取法是：全部圆形苹果(7) + 全部圆形桃子(9) + 全部西瓜(12)，不含五角星苹果和五角星桃子。

此时共 7+9+12 = **28 个**，仍不满足任何条件：
- AC 有但 PS=0 → 第一种不成立
- PC 有但 AS=0 → 第二种不成立

## 保证成功

摸满 28 个后，剩下的只有 PS(6) 与 AS(7)。第 29 个无论摸到哪一个：
- 摸到 PS → 与已有的 AC 组成"圆苹果+星桃子" ✓
- 摸到 AS → 与已有的 PC 组成"圆桃子+星苹果" ✓

因此第 29 个必定满足条件。

最终答案：29
