# 推理过程

规律：把单词的所有字母重新排列，能得到另一个（不同的）常见英文单词。

先验证给出的示例（都是"辅音-元音-辅音"结构的三字母词）：

- dad → add ✓
- dab → bad ✓
- gut → tug ✓
- low → owl ✓
- cat → act ✓

再逐一检查选项：

- A. leg → **gel**（常见词，凝胶）✓ 符合
- B. dam → **mad**（常见词，疯狂的）✓ 符合
- C. rat → **art / tar**（常见词，艺术／焦油）✓ 符合
- D. car → **arc**（常见词，弧）✓ 符合
- E. bin → 重排只能得到 **nib**（笔尖），这是一个很生僻、不常见的词；除此之外没有其他常见英文单词。✗ 不符合

其余四个都能重排出明显常见的单词，唯独 bin 只能对应到不常见的 nib，因此不满足"重排后得到一个常见英文单词"的规律。

最终答案：E
