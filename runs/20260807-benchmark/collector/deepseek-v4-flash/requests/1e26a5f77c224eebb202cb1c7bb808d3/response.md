设 \(p\) 为“三枚硬币同时出现正面”的概率。

由于三枚硬币中，出现反面的数量一定是偶数；三枚硬币时，反面数量只能是：

- 0 枚反面：即三枚都是正面；
- 2 枚反面：即恰好一枚正面。

所以实验结果只能是“三枚都是正面”或“恰好一枚正面”。

令：

- \(p = P(\text{三枚都是正面})\)
- 那么“恰好一枚正面”的总概率就是 \(1-p\)

计算正面数的期望：

\[
E(\text{正面数}) = 3p + 1(1-p) = 1 + 2p
\]

另一方面，每一枚硬币出现正面的边际概率都是 \(1/3\)，所以：

\[
E(\text{正面数}) = 3 \times \frac{1}{3} = 1
\]

因此：

\[
1 + 2p = 1
\]

得到：

\[
p = 0
\]

最终答案：0
